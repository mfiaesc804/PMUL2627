
# 📱 Práctica 1. Limitaciones y buenas prácticas en el desarrollo de aplicaciones móviles

**Módulo:** Programación Multimedia y Dispositivos Móviles\
**Curso:** 2.º DAM\
**Tipo:** Individual\
**Resultado de aprendizaje:** **RA1. Aplica tecnologías de desarrollo
para dispositivos móviles evaluando sus características y capacidades.**

------------------------------------------------------------------------

## 🎯 Objetivos

Con esta actividad aprenderás a:

-   📌 Identificar las principales **limitaciones y características de
    los dispositivos móviles** que condicionan el desarrollo de
    aplicaciones.
-   🔎 Analizar cómo esas limitaciones pueden afectar al **diseño,
    desarrollo y ejecución** de una aplicación móvil.
-   ✅ Proponer **buenas prácticas y recomendaciones** que permitan
    reducir o evitar los problemas detectados.
-   🔗 Relacionar las características del dispositivo con las decisiones
    que debe tomar un desarrollador.

------------------------------------------------------------------------

## 📝 Enunciado

Los dispositivos móviles presentan características y limitaciones
diferentes a las de un ordenador convencional. Estas pueden afectar
tanto al diseño de las aplicaciones como a su funcionamiento.

Realiza una pequeña investigación sobre **las principales limitaciones
que deben tenerse en cuenta al desarrollar una aplicación móvil**.

Para **cada limitación** identificada deberás explicar:

1.  🔹 **En qué consiste.**
2.  ⚠️ **Cómo puede afectar a una aplicación móvil.**
3.  ✅ **Qué buenas prácticas o recomendaciones** debería seguir un
    desarrollador para reducir su impacto.
4.  💡 **Un ejemplo concreto** de una aplicación o situación en la que
    pueda aparecer ese problema.

## 🧩 Ejemplo de lo que se pide

> ⚠️ **No puedes utilizar este ejemplo como uno de los apartados de tu
> trabajo.**

**Limitación:** conexión a Internet inestable.

**Problema:** una aplicación que dependa permanentemente de Internet
puede dejar de funcionar correctamente cuando el usuario pierde
cobertura o dispone de una conexión lenta.

**Buenas prácticas:** controlar los errores de conexión, informar al
usuario, evitar bloquear la aplicación y, cuando sea posible, permitir
trabajar temporalmente con información almacenada localmente.

**Ejemplo:** una aplicación de noticias podría mostrar las últimas
noticias descargadas aunque temporalmente no exista conexión.

### 🔗 Idea fundamental

**LIMITACIÓN → PROBLEMA → BUENA PRÁCTICA → EJEMPLO**

## ⚠️ Requisitos para superar la práctica

No bastará con presentar una lista de limitaciones y otra lista
independiente de buenas prácticas.

El alumno deberá demostrar que sabe establecer la relación:

**📱 Limitación → ⚠️ Consecuencia → ✅ Buena práctica → 💡 Ejemplo**

Es decir, deberá explicar **por qué una determinada característica o
limitación supone un problema y qué decisión debería tomar un
desarrollador para afrontarla correctamente**.
